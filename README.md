## 高防服务器是什么：先分清 DDoS 和 CC

高防服务器通常指自带 10Gbps 以上防御能力、能抵御 DDoS 和 CC 攻击的服务器，这是行业里通用的门槛定义。但对你真正有用的不是这个数字，而是分清自己挨的是哪种攻击——两者对应的防护产品完全不同。

DDoS 流量型攻击，是攻击方用海量垃圾流量把你的带宽和连接数打满，服务器本身还活着，正常用户却连不上。防护思路是资源对抗加流量清洗，攻击流量越大，你需要的防御带宽就越大。

CC 攻击则是伪装成正常用户，疯狂请求登录、搜索、提交这类消耗资源的接口。流量看着不大，CPU 和数据库先崩。它属于应用层攻击，堆防御带宽效果有限，主要靠 WAF 这类应用层防护来过滤。

很多人买错就错在这里：被 CC 打死的业务，买了一堆流量防御，该崩还是崩。

### 保底和弹性：高防的账单逻辑

买高防最容易踩的坑，是只看宣传里的“最高防御 X T”。云上高防的账单分两段：**保底防护**是每月固定付的部分，攻击来了随时能防；**弹性防护**是攻击超出保底后自动升上去的部分，按实际触发的攻击量后付费。

换句话说，宣传的最大防御值决定“能不能防住”，保底值决定“每月固定花多少”，弹性决定“被大打的时候账单会冲到多高”。开启弹性时可以自己设上限，不想被打时收到意外账单，就把弹性设个顶；预算想完全固定，也可以只买保底、不开弹性。

## 开通之后，这四个设置比选档位更影响效果

高防买回来不等于自动生效，接入和配置才是决定实际效果的部分。

1. **接入**：高防 IP 是代理转发模式，网站业务要把域名解析切到高防分配的 CNAME；游戏端口这类非网站业务，在高防控制台配置端口转发规则。
2. **源站保护**：把源站安全组设成只放行高防回源网段。否则攻击者拿到真实源站 IP，可以绕过高防直打源站，前面那层就白买了。这是最常见的事故来源。
3. **CC 规则**：在高防的网站配置或 WAF 里开启 CC 防护，针对登录、搜索、提交这些接口单独设频次限制。
4. **弹性上限**：弹性防护按攻击量后付费，攻击越大账单越高。设一个能接受的弹性峰值，或者评估后干脆不开。

## 常见问题

**10G 防御够用吗？** 取决于你的攻击峰值。10G 是高防的行业门槛，但要不要更高，应该看控制台里的实际攻击数据，别靠猜。

**高防 IP 和高防服务器必须二选一吗？** 不用。高防 IP 在带宽层清洗，源站服务器专心跑业务，两者搭配是常见的双层防护结构，单一手段对高并发业务往往不够。

**被打进黑洞怎么办？** 控制台可以自助解除，每天有次数限制，等它自动解除也行。如果攻击持续，解除后很快会再次进黑洞，这时该升级防御了。

**弹性防护会打出天价账单吗？** 会按实际攻击量计费，所以一定要设弹性上限；想预算完全可控，就只买保底。

**内地业务用阿里云高防要备案吗？** 要。域名指向中国大陆节点的服务都需要 ICP 备案；不想备案，选香港等海外地域。
